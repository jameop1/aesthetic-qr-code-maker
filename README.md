# Aesthetic QR Code Maker

Create customizable, scannable QR codes with custom styling, colors, patterns, and center branding logos. Perfect for menus, link-in-bio pages, business cards, and Wi-Fi sharing.

## Features

- **Custom Styling**: Adjust foreground colors, background gradients, corner square styles, and dot shapes.
- **Center Logo Integration**: Upload custom image or icon overlays centered in the QR code with automatic error correction adjustments.
- **Multiple Content Types**: Supports URLs, plain text, email, phone numbers, and Wi-Fi networks.
- **Export Options**: Download high-resolution PNG or vector SVG files.
- **Private & Client-Side**: Generates QR codes locally without sending sensitive data to external servers.

## Getting Started

Open `index.html` in any modern web browser or use it on https://jameop1.github.io/aesthetic-qr-code-maker/
